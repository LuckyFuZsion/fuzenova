# Cinder Automata - Gemini prompt pack

Generated by `node tools/build-prompt-pack.mjs` from `tools/sheet-plan.mjs`. **17 sheets, 164 objects** still to generate.

## Workflow
1. Attach an already-good sheet (e.g. `sheet-01-logistics`) to EVERY prompt as the style reference.
2. Paste the prompt. Save the result as `art/raw/<file>.png` (or .jpg) using the file name shown.
3. Run `node tools/slice-sheets.mjs` and check `art/contact/<file>.png`.
4. If the object count is wrong or things touch, regenerate that sheet.
